Nguyên lýPrinciple

Vùng nén chịu ứng suất Rb trên chiều cao x; cốt thép chịu kéo đạt Rs khi ξ = x/h0 ≤ ξR. Nếu αm vượt αR, cần đặt thép chịu nén. Khi x < 2a' thì bỏ qua thép chịu nén và lấy mô men quanh trọng tâm thép nén. Chịu cắt gồm phần bê tông Qb = 1,5Rbtbh0²/c (0,5–2,5Rbtbh0) và cốt đai Qsw = 0,75qswc0; c được dò trong khoảng h0–3h0 để tìm giá trị nhỏ nhất.The compression zone carries Rb over depth x; tension steel yields at Rs while ξ = x/h0 ≤ ξR. If αm exceeds αR, compression steel is required. When x < 2a' the compression steel is ignored and moments are taken about it. Shear combines concrete Qb = 1.5Rbtbh0²/c (0.5–2.5Rbtbh0) and links Qsw = 0.75qswc0; c is searched over h0–3h0 for the minimum.
